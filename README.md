# daily-progress-logger

A simple automation tool for tracking daily learning progress, coding practice, and project activity using markdown logs.

## Features

- Create timestamped daily logs
- Track learning progress
- Store coding exercises and notes
- Simple bash automation
- Markdown-based logging
- GitHub friendly structure

## Folder Structure

```text

daily-progress-logger/

├── README.md
├── LICENSE
├── scripts/
│   └── daily-log.sh
├── examples/
│   └── daily-log-example.md
└── logs/
    └── .gitkeep

```

## Usage

Run the logger script:

./scripts/daily-log.sh

A new markdown log file will be generated automatically.
